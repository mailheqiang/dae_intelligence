# 04 计算规则（尺寸 → 数量 → 金额）

> 全部从四套表的 Excel 公式反推，每条规则后面给出原表实例，可回查验证。

## 4.1 基本公式
```
行合计 = 单价 × 数量
分组小计 = SUM(该分组各行合计)
明细合计 = SUM(所有行)  或  SUM(各分组小计)
首页金额 = 明细合计 × 折扣   或   Σ(大类小计 × 该大类折扣)   或   直接填谈判整数
```

## 4.2 尺寸书写与换算
- 尺寸列写 `宽*深*高`（三维，mm）或 `宽*高`（二维）。例：`4040*600*2510`、`1300*1000`。
- 数量公式一律把 mm 换成 m 再相乘：`=4.04*2.51`。
- 数量单元格**保留公式**（不要写死数字），客户改尺寸时一眼能看出来源。
- 多段/多件用加法或乘法写在同一个公式里：`=4.3*0.9+1.6*0.9`（L 型）、`=0.85*2.45*3`（三面垭口）、`=2.6*0.6*2`（两块侧封板）。

## 4.3 投影面积（㎡）— 柜类默认算法
```
投影面积 = 宽(m) × 高(m)       ← 深度不参与
```
实例：
- 玄关整柜 `1800*450*2410` → `=1.8*2.41` = 4.338 ㎡
- 主卧衣柜 `4040*600*2510` → `=4.04*2.51` = 10.14 ㎡
- L 型吊柜 `4300*445*900 + 1600*445*900` → `=4.3*0.9+1.6*0.9`
- 冰箱上吊柜 `1850*750*320` → `=1.85*0.32`（矮柜也是宽×高）
- 客厅木制柜 `(8040-784)*600*2510` → 先扣掉柱子/门洞再乘：`=7.1*2.51`
- 食品储藏高柜 `870+780*310*2500` → 两段宽相加 `=1.65*2.5`

取值习惯：高度偶尔向上取整（2460→2.6、2510 保留），偶尔向下（950→0.85）。规则是**以实际图纸为准，取值时对我方略有利即可，不要离谱**。

## 4.4 门板面积 = 对应柜体投影面积
```
门板数量 = 该房间需要门板的柜体投影面积之和（直接引用柜体行的数量单元格）
```
实例：
- 玄关门板 `=P7+P9`（整柜 + 衣柜）
- 厨房吊柜门板 `=P34`；地柜/高柜/中岛门板 `=P36+P38+P45+P46+P51`
- 主卧门板 `=P70`；主卧卫门板 `=P82+P81+P78`
- 桃花源 柜门 `=7.54*2.6` 与柜体同公式
注意：开放格、金属层板、拉篮行不配门板；镜柜配"镜面门"而不是木门板。

## 4.5 展开面积 / 见光面（㎡）— 高档面材或 PP 膜时使用
- **见光面**：柜子外露的侧板、顶板、底板面积，按实际板面算。
  - 玄关鞋柜见光面 `=8.96+0.35*1.6`（正面 8.96 + 一块 0.35 宽侧板）
  - 入户门厅柜见光面 `2385*410` → `=2.385*0.41`（顶面：宽×深）
  - 衣帽间侧封板 `600*2600*2块` → `=2.6*0.6*2`
- **展开面积**：柜体内部背板+层板+立板全部板面之和（观承 10/13 电视柜：见光面 12.38 ㎡ + 内部展开 23.72 ㎡，分两行两个单价）。
- 何时用：PP 膜/实木贴皮等"按板面收费"的材质；标准 KS 板柜体直接用投影面积一口价。

## 4.6 延米（LM / m）— 厨房、台面、书桌、层板
```
延米数量 = 柜子长度(m)         ← 与高度、深度无关
```
- 厨房地柜 `6370*600*850` → 6.37 延米；吊柜 `1620*400*1000` → 1.62 延米
- **高柜延米单价 = 地柜延米单价 × 3**（`R152=R150*3`、`R176=R175*3`）
- 台面 `6370*600` → 6.37 延米；前沿加工同长度；台下盆加工按"项"
- 岩板浴室柜台面 `740*600` → 1.48 延米？（原表 0.74m 写成 1.48，疑为两块/双面，报价时按实际长度）
- 金属层板 `2.4米 3根` → 7.2 m
- 推拉门轨道延米 = 门洞宽 × 2（810 → 1.62；1700 → 3.4；2900×3樘 → 8.7）

## 4.7 按樘 / 套 / 个 / 项 / 块 / 根 / 组
| 单位 | 用于 | 数量来源 |
|---|---|---|
| 樘 | 室内门（含门套门扇标准五金） | 数门洞 |
| 套 | 抽屉、裤架、拉手、门锁、滑轮、棚柱、层板托架、桌架 | 数个数 |
| 个/块/根 | 层板、挂衣杆、网篮、上梁板、鞋架 | 数个数 |
| 组 | 拉篮、衣架 | 数个数 |
| 项 | 五金包、灯带、加工费、镜子 | 每房间/每柜 1 项，包干 |

## 4.8 组合件公式
- 带镜柜浴室柜（易郡）：`=地柜宽×地柜高 + 镜柜宽×镜柜高`，如 `=1.15*0.32+0.9*1.15`
- 浴室柜带镜柜（主卫）：`=2.395*1.02+2.395*0.9`
- 管井 L 型检修板：`=(0.83+0.47)*2.3`（两边宽相加 × 高）
- Magge 柜门差价：把所有可见柜门面积逐段相加 `=5*0.85+5*0.8+0.85*0.6+1.93*2.65+...` × 差价单价
- 双面/弧形墙板单价 = 平板单价 × 2（`R120=R119*2`）
- 下翻前沿单价 = 台面单价 / 2

## 4.9 折扣与汇总公式
```
世茂：V列 = S列×0.55（木作）；五金/代采行 V = S
      木作合计 = 总计 − 代采五金；最终 = 木作合计×0.55 + 代采五金
易郡：总价 = (门+收纳)×0.85 + 定制×0.8 + 代采×1.15 + 差价×0.8
桃花源：总价 = 合计×0.8；石材台面单独一张首页，不打折
观承：首页直接填成交价（0.64 / 0.71）
汇率：日元 → 人民币 ×0.07（HOUSTEC 1,007,500 日元 → 70,525 元）
```

## 4.10 报价前的自检清单
1. 每个柜体行是否都有对应门板行（除开放格/金属层板）？
2. 每个房间是否有一行"五金（铰链/轨道/灯带）"包干？
3. 台面/龙头/水盆/镜子/筒灯：含还是不含，备注写清。
4. 数量单元格是否保留公式？
5. 门板数量是否引用柜体单元格而不是手输？
6. 代采品是否单独分组且不打折？
7. 首页分项小计之和 = 明细合计？
