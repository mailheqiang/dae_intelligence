# 03 房间与家具关联（空间维度：一个房间通常会报哪些东西）

> 用途：拿到户型图/客户需求时，按房间逐个过一遍"清单"，不漏项。每项后面括号里是四个项目中实际出现过的写法。
> 与 02 的关系：这里回答"这个房间有什么家具"，02 回答"这件家具拆成什么部件"。

## 玄关 / 门厅 / 过厅
- 带壁龛整柜（筒灯甲方自采）、入户门厅柜 + 柜门 + 见光面
- 旋转鞋架（NUOMI/悍高成品）、鞋柜（棚柱式）
- 衣柜（挂衣杆、层板含）
- 门板（= 整柜 + 衣柜投影面积和）
- 洗衣间暗门、客卫暗门（樘）+ 日本 UN 门拉手
- 五金（铰链、门挡）
- 墙板（玄关/过厅）、垭口
- 穿衣镜

## 客厅 / 会客厅
- 木制柜（电视柜整墙）+ 门板（GU 框）
- 电视柜：主框架及见光面 / 背板层板立板（PP 膜按展开面积）
- 金属层板（含灯带）
- 造型木皮拼花垭口（三面）、阳台木饰面垭口
- 五金（铰链）
- 低地台、客厅顶板

## 餐厅
- 餐边柜木制柜（高档 11340 档）
- 双扇拉门（㎡）
- 餐边柜金属层板（含灯带，按 m）、玻璃层板（含灯带，㎡）
- 五金（抽屉轨道、移门轨道、灯带）
- 岩板台面 / 背板（通常不含，需注明）

## 厨房 / 西厨 / 中厨 / 食品储藏室 / 设备间
- L 型吊柜 + 灯带、L 型地柜、冰箱上吊柜、高柜
- 直型吊柜木制柜 + 直型玻璃吊柜门、直型木制柜体 + 直型玻璃门、直型地柜 + 五金 + 灯带
- 中岛坐人侧柜、中岛电器侧柜、U 型中岛、岛台地柜
- 门板：吊柜门板 / 地柜高中岛门板
- 拉篮系列（悍高转角、窄身、格栅；日本 DAYDO 下拉篮；百隆乐薄抽）
- 橱柜五金（百隆）、中岛五金、轨道插座
- 包柱墙板、墙面层板、见光板
- 台面（岩板/大理石/人造石）+ 前沿 + 台下盆加工
- 水盆 + 龙头（代采）
- 厨房口袋门 + 轨道、中厨推拉门（多樘）
- 食品储藏高柜、隐形木门（储藏室）
- 设备间木制柜 + 外挂拉门
- 西厨可按"延米包干"（柜体+门板+五金 8250/延米）

## 主卧
- 衣柜（柜体、含五金）+ 门板（GU）+ 抽屉 + 裤架 + 玻璃门
- 书桌及书桌上柜（镜子甲方自采）、书桌桌架
- 金属层板（含灯带）
- 五金（铰链）、抽屉轨道
- 暗门 + UN 拉手、单开门、推拉门 + 轨道 + 滑轮
- 床头墙板 + 侧板 + 顶板 + 立板、吊顶墙板、门旁墙板

## 主卧衣帽间 / 衣帽间
- 整柜方案：衣帽间柜（㎡）+ 柜门 + 侧封板 + 中岛 + 抽屉 + 饰品盒 + 玻璃门 + 裤架
- 棚柱方案：棚柱背板（含 AA 柱）+ 层板 + 挂衣杆 + 抽屉 + 网篮 + 化妆板 + 收边条 + 2P/1P 折门
- 衣帽间顶板、衣帽间单开门/推拉门

## 主卧卫生间 / 客卫 / 卫生间
- 浴室柜地柜（台面龙头水盆甲方自采）、浴室柜吊柜/镜柜、吊柜镜面门/铝框镜面门、高柜
- 马桶区吊柜、马桶间金属龛、马桶水箱装饰板、马桶区墙板
- 门板、五金（铰链、灯带）、UN 拉手
- 木门 / 暗门 / 推拉门（金属玻璃）+ 轨道 + 滑轮
- 台面（岩板/大理石）+ 前沿 + 台下盆 + 钢架 + 弧形加工
- 智能镜
- 代采：龙头、台下盆、恒温花洒、智能马桶、整体浴室柜、整体卫浴

## 洗衣间 / 家政间 / 工具间
- 木制吊柜、地柜、高柜、洗衣机房地柜/吊柜/高柜（延米）
- C 型铝型材层板架、管井检修包封板、洗衣机封板
- 棚柱式外衣杂物区 + 挂衣杆 + 层板
- 定制柜（㎡）+ 人造石台面 + 五金及灯带 + 镜子 + 洞洞板
- 衣架（金属）、门板、五金
- 口袋门、2P 折门

## 次卧 / 女儿房 / 客卧 / 保姆房 / 阿姨房
- 定制木柜（衣柜）+ 门板（GU）+ 抽屉轨道 + 五金
- 书桌 + 吊柜（镜子自采）、金属层板、金属柜（含灯带）
- 棚柱式 + 层板 + 抽屉 + 挂衣杆 + 网篮
- 电视柜 + 见光面 + 电视柜墙板
- 榻榻米柜体 + 床套
- 平开门 / 口袋门 / 推拉门 + UN 拉手 + 门锁 + 合页 + 门吸
- 床头墙板

## 书房 / 茶室 / 健身房 / 泡池
- 书柜、空格柜、桌板（开放格 ㎡）、书桌抽屉桌（延米）、挂墙层板
- 茶室展示柜、茶室墙板、茶室推拉门（金属玻璃）
- 健身房推拉门、泡池推拉门、泡池桧木墙板（造型/平板）+ 顶板

## 走廊 / 楼梯间 / 挑空区 / 休闲平台
- 走廊储物间柜、走廊开放柜体、走廊墙板、走廊挑空上顶板
- 楼梯处储物柜、楼梯间墙板、楼梯扶手（㎡，现场制作）、玻璃护栏 + 扶手 + 槽钢（延米）
- 休闲平台顶板 / 立面墙板

## 全屋
- 见光板补板（包干 ㎡）
- 门锁 / 合页 / 门吸 按樘数汇总
- 三维可调合页：普通 vs 液压

## 常见"不含项"（报价单要写明，避免纠纷）
- 台面、龙头、水盆、台下盆复合粘接工艺（甲方自采时）
- 壁龛筒灯、变压器、开关
- 镜子（书桌上柜）
- 岩板台面、墙面基层板（餐边柜）
- 台面基底板/框架：通常**已含**，要写"已涵盖"
