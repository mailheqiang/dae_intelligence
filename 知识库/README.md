# 大鄂报价工作流 · 知识库

从 `参考项目/` 下四套好特客报价表（观承、世茂、易郡、桃花源）中抽取，2026-09-28 建立。

| 文件 | 内容 | 更新频率 |
|---|---|---|
| 01_报价方式与表格结构.md | 三种报价组织方式、表格骨架、折扣/成交价规律、模板常量 | 有新模板时 |
| 02_家具拆解知识.md | 产品维度：一件家具拆成哪些可计价部件 | 遇到新品类时 |
| 03_房间与家具关联.md | 空间维度：每个房间通常报哪些东西、常见不含项 | 遇到新房型时 |
| 04_计算规则.md | 投影/展开/延米/樘 的算量公式、组合件公式、自检清单 | 稳定 |
| 05_单价表.md | 整理版单价（按部件类型、档位、来源） | **每月** |
| 05_单价表.csv | 脚本原始抽取的逐行单价（544 行，含来源/日期） | **每月**，由脚本生成 |
| 06_报价问答流程.md | 未来 Skill 的问答骨架 | 做 Skill 时 |
| 工具/extract_prices.py | 从 参考项目/*/*.xlsx 重新生成 05_单价表.csv | — |

每月更新单价：把新报价表放进 `参考项目/<项目名>/`，然后
```
cd 知识库/工具 && python3 extract_prices.py
```
再把变动同步进 05_单价表.md。
