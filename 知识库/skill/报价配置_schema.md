# 报价配置 JSON 结构说明（引导式问答的输出 / 生成脚本的输入）

一份报价 = 一个 JSON 文件。问答的每一步都在填这个 JSON 的某个字段；填完后运行
`python3 build_quote.py 配置.json` 生成 xlsx。你也可以手写/手改 JSON 直接生成。

```jsonc
{
  "meta": {
    "客户名": "孟总府邸",              // 明细表抬头
    "客户抬头": "孟女士",              // 订单首页 "xxx 御中"
    "项目名": "北京观承别墅35-107栋全屋定制家具",
    "项目地址": "北京观承别墅35-107栋",
    "报价日期": "2025-08-28",
    "订单编号": "HTBJ20250828003",     // 留空则按 HTBJ+日期+001 生成
    "生产周期": "40工作日（订单下单付全款开始计算）",
    "付款条件": "全款支付",
    "税": "含普通发票",
    "担当": "鄂"
  },

  "组织方式": "按楼层",     // 按楼层 | 按区域 | 按大类   → 决定明细表一级分组和首页的分项行
  "配置档位": "自定义",     // 基础 | 中配 | 高配 | 自定义 → 决定取价时默认查 05 单价表的哪一列
  "价格口径": "销售单价",   // 销售单价 | 牌价            → 明细表单价列的表头文字

  "折扣": {
    "方式": "谈判整数",     // 无 | 整单 | 按类别 | 谈判整数
    "整单折扣": 1.0,        // 方式=整单 时用：首页 = 合计 × 整单折扣
    "按类别": {"木作": 0.55, "代采": 1.0, "门": 0.85, "收纳": 0.85, "定制": 0.8, "石材": 1.0},
    "成交价": 158000        // 方式=谈判整数 时用：首页直接填这个数
  },

  "不含项": ["台面、龙头、水盆由甲方自采", "壁龛筒灯、变压器、开关不含"],
  "说明": ["玻璃实物待确认", "裤架/饰品盒参考0824PPT文件"],

  "分组": [                 // 明细表的一级分组，顺序即输出顺序
    {
      "名称": "二层主卧衣柜",   // 明细表 B 列合并单元格显示的文字；首页分项行也用它
      "楼层": "二层",           // 三个维度都填，方便以后换组织方式重新分组
      "房间": "主卧",
      "家具": "衣柜",
      "部件": [
        {
          "名称": "二层主卧衣柜",       // 明细表"内容"列
          "材质": "KS-5055",            // 颜色/材质/品牌
          "尺寸": "",                   // 原始尺寸 mm，如 "4040*600*2510"，可空
          "数量": "9.36",               // 字符串；可写公式 "=1.23+1.3*2"（保留到 Excel）
          "单位": "㎡",                 // ㎡ | 延米 | 套 | 个 | 项 | 樘 | 块 | 根 | 组 | m
          "单价": 2750,
          "说明": "柜体、含五金",       // 明细表"内容说明"列
          "类别": "木作",               // 木作 | 代采 | 门 | 收纳 | 定制 | 石材 → 按类别折扣用
          "备注": ""
        }
      ]
    }
  ]
}
```

约定：
- `数量` 永远是字符串。以 `=` 开头则原样写入 Excel 作为公式（如 `=1.8*2.41`），否则写数值。
- 门板行的数量可以引用同组柜体行：`"数量": "=@柜体"` 表示"本组内名称含'柜体'的行的数量之和"；`"=@二层主卧衣柜"` 表示引用本组内同名行。脚本会解析成单元格引用。
- `类别` 缺省为 `木作`。折扣方式 = 按类别 时，首页分项按类别汇总再乘各自折扣。
- 三档报价：同一 JSON 复制三份只改 `配置档位` 和各行 `单价`（或在问答里让脚本按 05 单价表自动换档）。
