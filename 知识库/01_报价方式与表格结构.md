# 01 报价方式与表格结构

> 来源：观承（2025-08-28 / 2025-10-13）、世茂PJ（2026-02-07）、易郡（2026-09-12）、桃花源（2026-09-10 基础/中配/高配）四套好特客报价表。
> 这一份回答"一张报价单长什么样、有几种组织方式、总价怎么从明细算到首页"。

## 1. 所有报价表的共同骨架

每个 xlsx 都是两张表：

| 工作表 | 作用 | 关键单元格 |
|---|---|---|
| **订单首页** | 给客户签字的封面：客户名、项目名、金额、生产周期（40/60 工作日）、付款条件（全款）、供方信息、**分项汇总**（每行引用明细表的小计） | `D9 = 金额` ← `Q26` ← 明细小计；`Q37/Q38` 常带折扣公式 |
| **内容 / 零售价 / 附件** | 明细表：一行一个"可计价的部件"，`合计 = 单价 × 数量` | 观承 `I = H*E`；世茂 `S = R*P`；易郡/桃花源 `S = R*O` |

明细行的字段（各表命名略有差异，本质是同一套）：

`分组（楼层/区域/大类） → 产品名称 → 颜色/材质 → 尺寸(mm) → 说明 → 数量 → 单位 → 单价 → 合计 → 备注`

世茂表字段最全，另有：门扇样式、门框种类（如 GU）、柜体材质、标准五金（丁番番号+色）、把手（+色）、OPTION1（名称+色）。这些"可变项"决定了同一个产品名对应不同单价。

## 2. 三种报价组织方式（一级分组不同，明细行结构相同）

### 方式 A：按楼层 → 房间/家具 → 部件（观承）
```
二层主卧衣柜            ← 一级：楼层+房间+家具
  ├ 二层主卧衣柜  KS-5055  9.36 ㎡  柜体含五金  2750
  ├ 抽屉          KS-5055  3 套     抽屉含五金  1780
  ├ 裤架          悍高成品  2 套                1585
  └ 玻璃门        待确认    7.36 ㎡  玻璃门含五金 2680
二层次卧衣柜 / 二层中厅书柜 / 三层衣帽间 / 三层衣帽间棚柱收纳 / 一层西厨 ...
```
- 一级分组在 B 列（合并单元格），K 列是隐藏的分组小计（`=I8+I9+I10+I11`）。
- 首页只写一行"1层、2层、3层定制家具"，金额是**谈判后的成交价**（158000），不是明细合计（246423.8）。
- 适合：别墅类、客户按楼层验收/付款的项目。

### 方式 B：按使用区域 → 产品 → 可变项（世茂）
```
玄关  → 带壁龛整柜 / 旋转鞋架 / 衣柜 / 门板 / 洗衣间暗门 / 客卫暗门 / UN门拉手 / 五金 / 墙板
客卫  → 浴室柜地柜 / 浴室柜吊柜 / 吊柜铝框镜面门 / 门板 / 五金
洗衣间 → 木制吊柜 / C型铝型材层板架 / 管井检修板 / 地柜 / 高柜 / 五金 / 门板
过厅 → 垭口
餐厅 → 餐边柜 / 双扇拉门 / 五金 / 金属层板 / 玻璃层板
厨房(+储藏室+设备间) → L型吊柜 / 灯带 / L型地柜 / 冰箱上吊柜 / 高柜 / 拉篮若干 / 五金 / 中岛 / 直型柜 / 门板 / 包柱墙板 / 口袋门+轨道
客厅 → 木制柜 / 金属层板 / 造型木皮拼花垭口 / 五金 / 门板 / 阳台木饰面垭口
主卧 → 衣柜 / 书桌及上柜 / 金属层板 / 五金 / 抽屉轨道 / 门板 / 暗门 / UN门拉手
主卧卫生间 → 浴室柜地柜 / 吊柜 / 镜面门 / 高柜 / 马桶区吊柜 / 金属龛 / 水箱装饰板 / 墙板 / 五金 / 门板 / 拉手 / 木门
女儿房 → 定制木柜 / 书桌+吊柜 / 金属层板 / 金属柜 / 五金 / 门板 / 抽屉轨道 / 平开门 / 拉手
阿姨房 → 口袋门
全屋 → 见光板补板（30㎡ 包干）
```
- U 列是各区域小计（`=SUM(S7:S15)`），首页按区域列出 12 行小计。
- V 列 = 木作行 × 0.55 折扣；五金/代采行不打折（`=S13`）。
- 表尾：`木作合计 = 总计 − 代采五金`；`最终金额 = 木作合计×0.55 + 代采五金`。
- 适合：精装/设计师主导的项目，客户按房间比价。

### 方式 C：按产品大类 → 楼层 → 单品（易郡、桃花源）
```
易郡：  1 室内门、收纳门 | 2 收纳（棚柱系统） | 3 定制（按㎡/延米） | 4 代采（卫浴洁具） | 5 差价项（Magge柜门）
桃花源：1 定制木门 | 2 定制柜 | 3 定制墙板 | 4 楼梯间护栏及扶手 | 5 浴室柜及洗衣机柜 | 6 定制橱柜
        每个大类内部再按 地下一层 / 一层 / 二层 / 楼梯间 分小计
        石材台面（天然石材+进口岩板）单独一套 首页+附件
```
- 首页每个大类一行，折扣**按大类不同**：
  - 易郡：`总价 = (门+收纳)×0.85 + 定制×0.8 + 代采×1.15 + 差价×0.8`（代采是加价 15%，不是打折）
  - 桃花源：`总价 = 合计×0.8`（全部八折）
- 桃花源同一套明细做了 **基础 / 中配 / 高配** 三个版本：行完全一致，只改材质列和单价列（见 05 单价表"档位"列）。
- 适合：整栋交付、客户要选配置档位、或者门/柜/墙板由不同工厂供货需要分开核算的项目。

## 3. 三种方式之间的关系

同一个项目可以在三种方式间转换，因为最小单元都是"部件行"：

```
部件行 = {楼层, 房间/区域, 家具, 部件, 材质/颜色, 数量, 单位, 单价}
按楼层报  = 以 楼层→家具 分组求和
按区域报  = 以 房间/区域 分组求和
按大类报  = 以 部件类型（门/柜/墙板/五金/石材）分组求和
按单件报  = 只取某一件家具下的所有部件行
```
所以知识库的核心是：**02 拆解（家具→部件）**、**03 关联（房间→家具）**、**05 单价（部件→单价）**、**04 规则（尺寸→数量）**。给客户报价时先选组织方式，再从部件行汇总。

## 4. 折扣 / 成交价规律（重要，直接影响利润）

| 项目 | 明细牌价合计 | 首页金额 | 折扣率 | 说明 |
|---|---|---|---|---|
| 观承 8/28（1-3层） | 246,423.8 | 158,000 | 0.64 | 首页直接填谈判后整数 |
| 观承 10/13（地下二层） | 50,892.8 | 36,000 | 0.71 | 同上 |
| 世茂 PJ | 1,116,922.9 | 635,094 | 木作 0.55 + 五金 1.0 | 公式化 |
| 易郡 | 646,885 | 555,184.9 | 门收纳 0.85 / 定制 0.8 / 代采 1.15 | 公式化，按大类 |
| 桃花源 高配 | 1,732,888.6 | 1,386,310.9 | 0.8 | 公式化，整单 |
| 桃花源 中配 | 1,283,231 | 1,026,585 | 0.8 | |
| 桃花源 基础 | 1,135,859 | 908,687 | 0.8 | |

结论：
1. 明细表里的单价是**牌价（零售价）**，留出了 20%–45% 的谈判空间；实际成交 0.55–0.85。
2. 代采品（成品五金、洁具）**不打折**，甚至加价 15%（代采服务费）。
3. 折扣位置：要么在首页公式里，要么首页直接填整数成交价；明细表永远保持牌价，方便客户加减项。
