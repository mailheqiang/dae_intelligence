# 06 报价问答流程（未来 Skill 的骨架）

> 目标：客户资料（户型图/需求表）进来 → 通过几轮问答确定报价方式与配置 → 从 02/03/05 拼出部件行 → 按 04 算量 → 输出与参考项目同格式的 xlsx（订单首页 + 明细）。

## 第 0 步：读取输入
- 客户名、项目名、地址、报价日期、订单编号（HTBJ+日期+序号）
- 户型图 / CAD / 需求清单：识别楼层与房间，每个房间对照 03 生成"候选家具清单"

## 第 1 步：三个决定性问题（问答）
1. **报价组织方式**：按楼层（观承式）/ 按房间区域（世茂式）/ 按产品大类（易郡、桃花源式）？
   - 客户是设计师/工程公司 → 区域式（方便他们对图）
   - 客户是业主、别墅多层 → 楼层式
   - 需要给客户选档位、或门/柜/墙板分包 → 大类式 + 基础/中配/高配三版
2. **配置档位**：基础（住友板+普通门）/ 中配（PP 膜）/ 高配（实木贴皮）？或 KS 板 / PP 膜 / GU 门框？
3. **含不含**：台面、龙头、水盆、镜子、筒灯、洁具代采、岩板墙板——每项问清，写进备注列。

## 第 2 步：逐房间确认（每个房间一轮）
按 03 的房间清单问："X 房间需要：柜体 ✔/✘、门板 ✔/✘、抽屉 n、裤架 n、玻璃门 ✔、金属层板 ✔、门（类型）……尺寸 W*D*H？"
- 尺寸未知时先按图估，数量单元格写公式并标"待确认"。
- 每个房间自动补一行"五金（铰链/轨道/灯带）项"。

## 第 3 步：算量（04）
- 柜体 → 投影 ㎡；门板 → 引用柜体；厨房/台面 → 延米；门 → 樘；配件 → 套/个/项。
- 高档见光面 / PP 膜 → 按见光面或展开面积单列。

## 第 4 步：取价（05）
- 先按"部件 + 材质档位 + 单位"在 05 查；查不到用 5.9 的规律估并标黄。
- 代采品单独分组。

## 第 5 步：折扣与首页
- 明细保持牌价；首页按 01 §4 的三种方式之一写折扣公式或成交整数。
- 输出：`报价YYYY年M月D日.xlsx`（订单首页 + 内容/零售价/附件）；三档时输出三个文件。

## 第 6 步：自检（04 §4.10）并给出"报价说明"
- 列出：不含项、待确认尺寸、代采品清单、生产周期、付款条件。
