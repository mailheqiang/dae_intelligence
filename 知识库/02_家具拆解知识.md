# 02 家具拆解知识（产品维度：一件家具 = 哪些可计价部件）

> 原则：**能单独计价的就单独成行**。柜体、门板、五金、成品配件、灯带、台面永远分开报，客户加减项时不用重算整柜。
> 每个部件后面标注了计价单位，单价见 05。

## 2.1 柜类通用拆解（衣柜 / 储物柜 / 电视柜 / 餐边柜 / 书柜 / 玄关柜）

```
一个柜子
├ 柜体（含背板、层板、立板、标准五金）        ㎡（投影：宽×高）
│   └ 见光面 / 侧封板（柜子露在外面的侧面、顶面）  ㎡（实际板面）  ← 高档材质时单列
├ 门板（平开门板 / 玻璃门 / 铝框镜面门 / 隐形门板）  ㎡（= 对应柜体投影面积）
├ 内配
│   ├ 抽屉（含轨道）                                套 / 个
│   ├ 裤架、饰品盒、拉篮、伸缩挂衣架（悍高/百隆成品） 套
│   ├ 层板（木 / 玻璃 / 金属，金属常含灯带）        块 / 套 / ㎡ / 延米
│   └ 挂衣杆                                        根 / 套
├ 五金包（铰链、抽屉轨道、移门轨道）               项（一个柜/一个房间一项，包干）
├ 灯带                                              项
├ 拉手（日本 UN 拉手 / 国产 / 暗抠手）              套
└ 补板：化妆板（高度不够时补高）、收边条、上梁板、包柱板  套 / 块 / ㎡
```

## 2.2 棚柱式收纳系统（衣帽间常用，可替代整柜）

## 2.3 厨房（橱柜）

> 2026-10-03 起（客户反馈）：厨房 **柜体与门板拆开报**——地柜柜体/吊柜柜体按延米，地柜门板/吊柜门板按面积（长×高），门板材质可选 混油/烤漆/PP膜/实木贴皮；吊柜长度可与地柜等长也可单独指定；吊柜门型可选平开/折叠门/上翻门（折叠门每约 900mm 加一组折叠门五金）。


```
厨房
├ 地柜（直型 / L 型 / U 型）           ㎡（投影）或 延米
├ 吊柜（直型 / L 型 / 冰箱上吊柜）     ㎡（投影）或 延米
├ 高柜（食品储藏高柜、电器高柜）       ㎡ 或 延米（延米价 = 地柜价×3）
├ 中岛（坐人侧柜 / 电器侧柜 / U 型中岛） ㎡ 或 延米
├ 门板：吊柜门板 / 地柜高柜中岛门板     ㎡（= 柜体投影），吊柜门板单价高于地柜门板
├ 台面：人造石 / 岩板(国产、进口) / 天然大理石   ㎡ 或 延米
│   ├ 前沿加工费（下翻边）             延米
│   ├ 台下盆加工费                     项
│   ├ 弧形加工费                       项
│   └ 钢架（台面支撑）                 延米
├ 拉篮：调味拉篮 / 锅篮 / 碗篮 / 转角拉篮 / 窄身拉篮 / 格栅拉篮 / DAYDO 下拉篮 / 百隆乐薄抽   组 / 套
├ 橱柜五金（百隆铰链、抽屉轨道）       项
├ 灯带（吊柜底灯带、直型柜灯带）       项
├ 轨道插座                             套
├ 见光板 / 包柱墙板 / 墙面层板          ㎡
├ 水盆 + 龙头（汉斯格雅 / KVK / 骊住）  套（代采）
└ 厨房口袋门 + 口袋门轨道（纽森）       ㎡ + 项
```

## 2.6 门类（室内门是独立大类，按"樘"计）

| 门型 | 说明 | 计价 |
|---|---|---|
| 平开门 | 单开，24 门框 / 无框 | 樘 |
| 暗门 / 隐形门 | 与墙板齐平，含木饰面板 | 樘（单价最高档） |
| 外挂拉门 / 推拉门 | 实木贴皮 或 金属玻璃 | 樘（实木）或 ㎡（金属玻璃）+ 轨道(延米=门宽×2) + 滑轮(套) |
| 口袋门 | 藏墙内，无框 | 樘 或 ㎡ + 轨道(项，德国纽森) |
| 37 折门 | 三七比例折叠 | 樘 |
| 1P 折门 / 2P 折门 | 折叠门，隐框/无框 | 套 |
| 双扇拉门 | 餐边柜前 | ㎡ |
| 垭口 / 木饰面垭口 / 造型木皮拼花垭口 | 三面展开 | ㎡ |
| 门配件 | 门锁、三维可调合页、液压合页、防风门吸、上梁板、UN 拉手 | 套 / 块 |

门的可变项：**门扇样式**（平板…）、**颜色**（木色/标准色）、**门框种类**（24 / 无框 / 隐框 / GU）、**材质**（实木贴皮 / 金属玻璃 / 混油）、**尺寸**（洞口 900*2300 常规，超高 2800 加价）。

## 2.9 配件（任意柜子都可追加）
- 每件柜类家具都可以追加"配件/五金"行：抽屉、挂衣杆、层板、树脂层板、裤架、饰品盒、网篮、各类拉篮、灯带、柜锁、UN 拉手、铰链包、折叠门五金……取价键见 05 / 价格档位.json 中标 `_配件` 的项。
- 目录里没有的配件可"自定义"：填名称、数量、单位，单价可留空；生成报价时会自动写入 价格档位.json（`自定义.<名称>`，标待定价），在"知识库 → 待定价清单"补价后下次自动生效。
- 所有柜类默认预放"抽屉 × 0"，衣柜额外预放"挂衣杆 × 1""柜锁 × 0"。
